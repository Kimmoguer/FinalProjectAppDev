## How to Run the Project

1. **Start the Server:**
   Open your terminal in the project folder and run:
   ```bash
   php artisan serve
   ```

2. **Access the App:**
   Open your browser and go to:
   [http://127.0.0.1:8000](http://127.0.0.1:8000)

---

##  How to Stop the Project

1. Go back to the terminal where the server is running.
2. Press **`Ctrl + C`** on your keyboard.

---

## Features

- **Eloquent ORM:** All database operations (Create, Read, Update, Delete) are handled using Laravel's powerful ORM.
- **Glassmorphism UI:** Clean, dark-mode design with subtle blurs and vibrant accents.
- **Status Filtering:** Organizes tasks by tabs (To Do, In Progress, Completed, etc.).
- **SQLite Database:** Uses a local file-based database for zero-config setup.
- **Automated Tests:** Includes Feature Tests to ensure 100% functionality.
